# 个人 Agent 工作流工具箱

skeleton 的花园 · 本地工具实践

把项目推进、课程练习、简历整理和演示文稿规划封装为可复用的 Codex Skills。每套流程组合任务说明、参考资料、模板与交付检查。

## 项目起点

经常重复的任务，能否积累成下一次直接可用的方法？

我从重复出现的工作中提取步骤，为项目推进、课程练习、简历整理和演示文稿规划分别编写任务说明。参考资料、模板和检查脚本跟随流程保存，使下一次任务能够复用已有方法，并在交付前完成检查。

## 我做了什么

- 把已有工作流封装为本地 Codex Skills。
- 组织说明、参考资料、模板、Agent 配置与 Python 校验脚本，让任务有输入、有交付、有检查。

## 做出的成果

- 形成项目推进、课程练习、简历材料和演示文稿规划等本地工作流。
- 将模板、Agent 配置和 Python 校验脚本组织为可再次调用的工具包。

## 实现过程

1. 收集重复任务步骤
2. 写入说明与参考
3. 准备模板和配置
4. 执行任务流程
5. 用脚本校验交付

## 设计取舍与收获

可复用的工作流需要明确输入、交付物和检查方法。我将这些要求写进工具，让下一次任务能从清楚的起点开始。
