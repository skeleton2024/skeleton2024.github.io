成固县小社会模拟器
早期原型
一个围绕长期状态构建的 AI 社会模拟原型。人物的身体、家庭、关系与任务会随着行动持续变化，Web、CLI 和 HTTP API 共用同一套世界状态。
下载项目介绍
一次行动，能在世界里留下什么？
人物身体、家庭、关系网络和长期任务共同组成持续状态。规则兜底与可选 AI 裁判解释行动如何改变状态，让 Web、CLI 与 HTTP API 使用同一套世界。
我做了什么
  • 建模人物、家庭、地点、关系图与任务线程。
  • 组织规则兜底与可选 AI 裁判，将状态、行动和结果写入同一循环。
做出的成果
  • 形成 Web、CLI、HTTP API 共用状态的早期可演示原型。
  • 公开可直接运行的源码，支持本地规则兜底、存档和行动记录。
实现过程
  1. 人物、家庭与地点
  2. 接收玩家行动
  3. 规则与可选 AI 裁判
  4. 更新关系和任务线程
  5. 保存长期世界状态
设计取舍与收获
我将世界状态与界面分开，把行动造成的变化写入记录。这样无论从哪个入口进入，都能接着同一个世界继续。
