黑客松项目

一个将自然语言意图组织为链上工作流的双人黑客松项目。我参与需求拆解、产品原型、模块集成、演示和 ETHGlobal 提交。

下载项目介绍

自然语言怎样成为用户看得懂的链上操作？

把用户意图转换为经过校验的结构，再用 Skill Registry 和 Workflow Orchestrator 组织有依赖的操作；协议实现与 UI 分开，交易状态和用户确认留在流程内。

我做了什么

  • 参与需求拆解、产品原型、演示及参赛提交。
  • 基于官方示例集成改造，处理意图校验、工作流与协议模块。

做出的成果

  • 完成意图输入、结构校验与工作流编排的参赛原型。
  • 制作项目演示并完成 ETHGlobal 提交，公开页面保留项目介绍与界面。

实现过程

  1. 自然语言意图
  2. 结构化校验
  3. Skill 与依赖编排
  4. 用户确认
  5. 协议执行与结果聚合

设计取舍与收获

用户需要在确认之前看懂操作内容。我把意图校验、操作依赖和交易状态保留在产品流程中，减少执行过程中的信息落差。
