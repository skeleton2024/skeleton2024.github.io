TeamMind

本地 Alpha

把会议、用户反馈和项目进展整理成团队记忆，再连接下一步行动。TeamMind 是我设计并实现的本地工作台，覆盖信息收集、行动简报和结果回流。

下载项目介绍

下一步行动，能否保留它的来由？

我从团队信息分散、行动缺少上下文的问题出发，将原始来源、结构化信号、长期记忆和行动简报分开建模。工作台通过本地规则推进流程，用户可以检查来源、编辑简报，并把执行结果回填为新的记忆和后续行动。

我做了什么

  • 独立完成产品定义、信息架构、数据模型和 JavaScript 原型。
  • 实现收件箱、记忆治理、行动简报与结果回流，并为每项行动保留来源和确认步骤。

做出的成果

  • 跑通来源 → 信号 → 记忆与行动 → 简报 → 结果回流的本地流程。
  • 实现持久化、编辑、状态管理与异常处理；以 5 个 Wave、30+ Issue 组织迭代。

实现过程

  1. 收进原始上下文
  2. 提取与关联信号
  3. 治理记忆和项目状态
  4. 生成行动 Brief
  5. 人工复核与结果回流

设计取舍与收获

行动建议需要能回到具体来源，执行结果也需要回到记忆中。我把这两段连接放在产品的核心流程里。
