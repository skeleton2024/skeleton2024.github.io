Virtual Cell Experiment Triage
工作流 Demo · 示例数据
面向细胞扰动研究的实验优先级工作台。导入候选与目标状态后，集中查看排序依据、风险和首轮验证面板，帮助组织下一步实验。
下载项目介绍
有限的实验资源，先放在哪些候选上？
我把“先做哪些扰动实验”拆成一组可操作的信息：候选、目标状态、排序依据、风险与验证面板。原型支持 CSV 导入和小型示例，加入留一扰动检查及随机基线，让研究者可以把排序放到对照中阅读。
我做了什么
  • 设计候选扰动、目标状态、评分依据与验证面板的信息结构。
  • 实现 Streamlit 界面和 CSV 导入，加入留一扰动检查与随机基线对照。
做出的成果
  • 完成可运行的工作流 Demo，支持示例输入、候选排序与解释查看。
  • 把首轮候选与下一轮验证建议组织到同一界面。
实现过程
  1. 输入状态、目标与候选
  2. 读取 response / state CSV
  3. 已知签名对齐或近邻估计
  4. 候选排序与解释
  5. 验证面板与下一轮建议
设计取舍与收获
排序需要回答为什么排在前面、如何验证这两个问题。我把解释和验证面板放在排名旁边，方便研究者继续判断。
