SettlementCraft

核心循环原型

一个 Minecraft 聚落经营模组。我用 Java / Forge 连接建筑、职业、生产与运输，让食物、材料、装备和仓库库存参与聚落的日常运转。

下载项目介绍

一个聚落怎样靠真实资源运转？

通过阵营、建筑、资源和职业结构，把仓库、矿井与村民任务连到一起。库存、食物、材料和装备实际影响生产、搬运和人口活动。

我做了什么

  • 使用 Java / Forge 实现阵营、建筑、资源与职业领域结构。
  • 让真实食物、材料、装备和库存影响生产、搬运与人口活动。

做出的成果

  • 完成 V0.1 核心循环，连接阵营、仓库、矿井与村民任务。
  • 实现本地构建与调试，让生产、搬运和资源消耗进入同一套库存逻辑。

实现过程

  1. 玩家自有阵营
  2. 建筑与职业任务
  3. 生产和资源消耗
  4. 搬运、仓库与库存
  5. 材料支持后续活动

设计取舍与收获

先让一座聚落中的资源真正流动起来，建筑和职业才会互相产生影响。这条资源循环成为后续扩建的基础。
