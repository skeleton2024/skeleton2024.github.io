Pet VOC → BOM

规则工作流原型 · 模拟评论

把“牵引绳断了”这类宠物商品反馈整理为产品改进工单。这个 Streamlit 原型使用模拟评论，串起缺陷识别、根因假设、材料建议与人工审批。

下载项目介绍

一条差评，怎样变成可讨论的工程问题？

宠物电商实践让我注意到，用户说出的故障与供应链需要的工单信息之间存在距离。我以模拟评论建立示例，把原话映射到缺陷类型和根因假设，再生成可编辑的材料建议，让人工审阅始终能看见原始上下文。

我做了什么

  • 设计供应链分析 Prompt 与结构化工单 Schema。
  • 制作 Streamlit 界面，对照原评论与分析结果，支持编辑、确认和下载工单草稿。

做出的成果

  • 实现评论与工单对照界面，支持编辑改进建议、确认草稿并下载。
  • 将缺陷类型、失效模式、根因假设与 BOM 建议写入统一结构，交由人工确认。

实现过程

  1. 读取本地模拟评论
  2. 识别缺陷与失效模式
  3. 提出根因假设
  4. 生成可编辑 BOM 工单
  5. 人工审批并保留邮件草稿

设计取舍与收获

客服语言和工程语言之间有一段翻译工作。我保留原评论和根因假设，让审阅者能沿着同一条线检查建议。
